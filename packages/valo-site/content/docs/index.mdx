Valo is a WebGPU-native 2D render engine built with Rust and
[wgpu](https://wgpu.rs/). It follows the architecture of Flutter's
[Impeller](https://github.com/flutter/flutter/tree/master/engine/src/flutter/impeller):
no shader compilation at draw time.

Use the `valo` crate from Rust on native platforms or in a browser through
WebAssembly. JavaScript and TypeScript applications use `valo-web` — Valo's
own API or a Canvas2D-compatible adapter. Valo supports every platform wgpu
supports, including Windows, macOS, Linux, iOS, Android, and the web.

## Packages

- [`valo`](https://docs.rs/valo/latest/valo/) — Rust API on docs.rs ([native](/docs/guides/embedding-rust), [wasm](/docs/guides/rust-browser))
- [`valo-web/raw`](/docs/guides/raw-api) — JavaScript engine API
- [`valo-web`](/docs/guides/canvas2d) — Canvas2D adapter
- [`valo-capi`](/docs/guides/integrations) — C ABI

`valo-web` is a thin JavaScript wrapper over the same engine. A Rust app
compiled to WebAssembly imports [`valo`](/docs/guides/rust-browser) directly.
