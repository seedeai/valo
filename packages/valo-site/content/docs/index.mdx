title: What valo is
description: A 2D render engine in Rust on wgpu, with a Canvas2D-compatible layer compiled to WebAssembly.

valo is a 2D render engine. It records a display list on the CPU, plans its GPU
passes in one pure pass over that recording, and encodes them through WebGPU.

It takes Impeller's architecture — display list, record-time oracle, planned GPU
passes — and Skia's text architecture, and owns the orchestration between them.

## The frame

```text
record    DisplayListBuilder -> Arc<DisplayList>      CPU only, no GPU device, any thread
plan      cull -> depth assign -> reorder -> segment  pure CPU pass over the recorded ops
encode    render passes, breaking only where recorded (backdrop filters, advanced blends)
submit    stats: cpu/plan/encode ms, draws, culled, passes, atlas churn, GPU timestamps
```

Present and read-back belong to the host. valo never owns a window, a surface
loop, or a font source.

## What the layers are

There are two surfaces, and the difference matters when you choose one.

| | Import | You work with |
| --- | --- | --- |
| **Raw** — valo's own | `@valo/web/raw` | `DisplayListBuilder`, `Paint`, `Shader`, `Path`, `ImageFilter`, `ColorFilter`, `Paragraph` |
| **Canvas2D shim** | `@valo/web` | `CanvasRenderingContext2D`, as specified |

The Canvas2D layer is a *compatibility* surface, and therefore a strict subset.
Mask blur styles, backdrop blur, gradient spread modes, difference clips and
the retained display list itself have no Canvas2D spelling at all. If you are
porting an existing canvas application, start with the shim. If you are building
something new, the raw API is the engine.

## Invariants worth knowing early

- y-down, origin top-left, logical pixels until a transform says otherwise.
- `Color` is straight (unpremultiplied) sRGB. Premultiplication happens at the
  GPU boundary and blending is in sRGB space — the CSS and Skia look.
- Recording is GPU-free. A display list can be built on any thread, with no
  device in hand, and replayed later.
- The renderer holds no scene graph. Everything it keeps is a content-keyed or
  frame-scoped cache, which is where retained-mode performance comes from.
