Record what you want on a `DisplayListBuilder`, then submit the list. Each
command carries its own `Paint` — there is no global fill style.

This section is option-by-option. [Reference](/docs/reference/paint) is the
type encyclopedia; the playground has the same scenes if you want to edit
them full-screen.
